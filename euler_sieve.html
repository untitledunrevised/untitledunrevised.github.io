Euler 筛法

Euler 筛法，又称线性筛法，是一种可以在线性时间筛选出所有素数，并求出诸多数论函数的算法。

本文将介绍 Euler 筛法的基础用途，包括筛选 $[1, N]$ 之间的所有素数，和求出数论函数在 $[1, N]$ 上的值。

记号约定

  • $a \mid b$：$a$ 整除 $b$，即 $\exists q \in \Z$ 使得 $aq = b$。

算法描述

Euler 筛法流程简述为：从小到大枚举自然数 $n \in [2, N]$，然后从小到大枚举素数 $p$，若 $np \le N$ 则计算数论函数 $f(np)$ 的值然后筛掉 $np$，直至 $p \mid n$ 或 $np \gt N$。

#include <vector>

using std::vector;
using u64 = unsigned long long;

// config this
constexpr u64 N = 1'000'000;

bool vis[N + 1] = {};
vector<u64> primes;

void euler_sieve() {

    for(u64 n = 2; n <= N; ++n) {

        if(!vis[n]) {
            primes.push_back(n);
        }
        
        for(u64 p : primes) {
            if(n * p > N)
                break;
            vis[n * p] = 1;
            if(n % p == 0)
                break;
        }
    }
}

记录最小素因子

为了方便讲解，我们首先定义「最小素因子」。

最小素因子
对于 $n \ge 2$，其最小素因子 $\lpf(n) = \min\{p \in \mathbb P\colon p \mid n\}$。特别地，定义 $\lpf(1) = 1$。
